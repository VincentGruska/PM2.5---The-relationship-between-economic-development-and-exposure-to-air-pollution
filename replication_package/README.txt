================================================================================
HOW TO REPLICATE
================================================================================

Step 1 — Data preparation (Python)
  Requirements: Python >= 3.8, packages: pandas, numpy
  Run from the code/ folder:
    python merge_panel.py
  Output: data/panel_final.csv

Step 2 — Regression and visualisation (R)
  Requirements: R >= 4.1, packages: fixest, modelsummary, car
  Run from the code/ folder:
    Rscript regression_PM2.5_GDP.R
  Outputs: all five files in output/

================================================================================
REGRESSION MODELS
================================================================================

  M1  Pooled OLS             (baseline, no fixed effects)
  M2  Country FE             (absorbs time-invariant country characteristics)
  M3  Year FE                (absorbs global time trends)
  M3b Year trend             (continuous year trend, alternative to M3)
  M4  Two-way FE             (country + year, preferred specification)
  M5  Two-way FE + controls  (pop. density, urban %, industry %, trade %, renewables %)

All models use standard errors clustered by country. The EKC inverted-U is
confirmed in M4: turning point at ~$7,200 GDP/cap (95% CI: $1,626–$31,898).
